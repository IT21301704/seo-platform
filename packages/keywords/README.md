# @seo/keywords

Keyword research from Search Console data (M18), pure and deterministic: aggregation per country,
intent, ideas, quick wins, cannibalization (KWD-002), word-based clusters (fallback when no LLM),
automatic keyword-to-page map, content gaps and the primary-keyword check (KWD-001).

Search volume and difficulty need a keyword data provider (Phase 4) and are never estimated.
Jobs and storage: `apps/worker/src/keywords.ts`.
